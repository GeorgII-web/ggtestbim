# ggtestbim

3D game in Rust (Bevy). Build and run on Windows from WSL: `scripts/run-win.sh` (see `AGENTS.md`).

Endless procedural city: new chunks appear ahead, old ones vanish behind, and coming back builds something new.
Cars drive the streets, clouds drift overhead, things change behind your back, and someone watches from the windows.

Controls: WASD move (runs fast), Shift walk, Ctrl crouch (crouch + jump to climb through windows), Space jump, mouse look, click to grab the mouse, Esc to release it, R for a new world.
