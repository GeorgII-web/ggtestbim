# ggtestbim

3D game in Rust (Bevy). Build and run on Windows from WSL: `scripts/run-win.sh` (see `AGENTS.md`).

Endless procedural city: new chunks appear ahead, old ones vanish behind, and coming back builds something new.

Controls: WASD move (runs), Shift walk, Ctrl crouch (crouch + jump to climb through windows), Space jump, mouse look, click to grab the mouse, Esc to release it, R for a new world.
